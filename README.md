# Personal Portfolio — Bruno Santos

My personal website / portfolio.

🌐 **Live:** https://brunosantos-devsite.vercel.app

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- next-intl (EN / PT / ES)
- Deployed on Vercel

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
